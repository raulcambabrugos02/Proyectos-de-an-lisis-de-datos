⚽ La Liga 2015/16 Analytics: Comparative Player ProfilingAn advanced sports analytics project focused on evaluating and comparing offensive, creative, and defensive performance profiles in La Liga 2015/16, featuring a deep-dive comparison between Neymar Jr. (FC Barcelona) and Antoine Griezmann (Atlético de Madrid).📌 Project OverviewComparing players across teams with vastly different tactical styles (e.g., possession-based vs. low-block counter-attacking) often introduces bias into raw statistical comparisons.This project solves this challenge by implementing a Tactical Usage Rate (Cuota de Uso) metric alongside traditional volume and efficiency metrics, providing a normalized, multidimensional evaluation of player contributions.Key ObjectivesData Ingestion & Pipeline: Extract event-level data using statsbombpy for La Liga 2015/16.Contextual Normalization: Calculate individual player participation relative to total team actions (Usage Rate).Multidimensional Profiling: Group performance into 4 core pillars:Offense: Expected Goals ($xG$) and actual goals scored.Creation: Key passes, shot-creating actions, and pass completion rate.Dribbling: Completed take-ons and success percentages.Defense: Defensive pressures, ball recoveries, and defensive workload.Data Visualization: Design intuitive radar/pizza charts using mplsoccer for comparative analysis.🛠️ Tech Stack & DependenciesLanguage: Python 3.8+Data Manipulation: pandas, numpyData Source: statsbombpy (StatsBomb Open Data)Visualization: mplsoccer, matplotlibMachine Learning (Optional Expansion): scikit-learn (for KNN similarity modeling)🚀 Getting StartedPrerequisitesEnsure you have Python installed on your system. You can install all required libraries using:pip install pandas numpy matplotlib mplsoccer statsbombpy scikit-learn
